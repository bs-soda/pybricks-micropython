## 1. The Socratic 5-Why Root Cause Chain

```text
Symptom: Autonomous robot executing multi-waypoint path tracking aborts with OSError: [Errno 110] ETIMEDOUT.
│
├── [Why 1] Why did the robot abort with ETIMEDOUT?
│   └── The motion iteration loop in pb_type_mdrobotbase.c evaluated elapsed_ms >= timeout_ms and returned PBIO_ERROR_TIMEDOUT.
│
├── [Why 2] Why did elapsed_ms exceed timeout_ms while the robot was moving normally?
│   └── The assigned timeout_ms was only 5000 ms, whereas the robot needed 8000 ms to travel between the waypoints at 100 mm/s.
│
├── [Why 3] Why was timeout_ms set to only 5000 ms for an 800 mm trajectory?
│   └── In pb_type_mdrobotbase.c:1948, the default timeout formula was hardcoded as:
│       timeout = (uint32_t)(num_points * 2000) + 1000;
│       With num_points = 2, it calculated 2 * 2000 + 1000 = 5000 ms.
│
├── [Why 4] Why was a fixed waypoint multiplier used instead of physical distance and velocity?
│   └── The initial implementation treated waypoints as discrete rapid waypoints under high-density curve sampling, ignoring sparse coarse waypoints with long straight segments.
│
└── [Why 5] (Root Cause) Why was physical kinematic modeling omitted from the deadline calculation?
    └── The temporal contract was not unified with the kinematic trajectory planner. Deadlines must be derived from cumulative Euclidean path arc length D = ∑ ||P_{i+1} - P_i|| and motion constraints (v, a, ω).
```

## 2. Quantitative Mathematical Bounds & Invariants

1. **Euclidean Path Length:**
   $$D = \sum_{i=0}^{N-2} \sqrt{(x_{i+1} - x_i)^2 + (y_{i+1} - y_i)^2}$$

2. **Kinematic Duration Formulation:**
   $$T_{cruise} = \frac{D}{v_{cruise}}$$
   $$T_{accel} = \frac{v_{cruise}}{a_{accel}}, \quad T_{decel} = \frac{v_{cruise}}{a_{decel}}$$
   $$T_{turn} = \sum_{k} \frac{|\Delta \theta_k|}{\omega_{turn}}$$
   $$T_{kinematic} = T_{cruise} + T_{accel} + T_{decel} + T_{turn}$$

3. **Dynamic Safety Deadline:**
   $$T_{deadline} = \max\left(1500\text{ ms}, \left\lfloor T_{kinematic} \times 1.5 \times 1000.0 \right\rfloor + 2000\text{ ms}\right)$$
